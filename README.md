# Baku Transit

A modern Android application for public transport in Baku, Azerbaijan.

## Features
- Real-time interactive map with Baku Metro lines.
- Accurate routing using GraphHopper (Foot and Car profiles).
- Bus route information and schedules.
- Smart trip planner.
- BakiKart calculator.
- Professional UI with Edge-to-Edge support.

## Technical Details
- **Map SDK:** MapTiler
- **Routing:** GraphHopper API
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **Architecture:** MVVM with Room Database
